## About

This repository contains my submission for Exercise 2: "SQL Aggregate Functions & Operators." The exercise covers 15 handwritten SQL queries based on 5 tables (`students`, `courses`, `enrollments`, `salaries`, and `projects`), focusing on aggregating, grouping, and filtering data.

## Contents

- `SQL-Exercise-2.pdf` – scanned handwritten SQL queries with expected output tables

## Topics Covered

- Aggregate functions with `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`
- Grouping results with `GROUP BY`
- Filtering groups with `HAVING`
- Removing duplicates with `DISTINCT`
- Filtering rows with `WHERE`, combining conditions using `AND`, `OR`, `NOT`, `IN`, and `BETWEEN`
- Sorting and limiting results with `ORDER BY` and `LIMIT`
- Renaming result columns with `AS` (aliases)
